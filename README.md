# aTz

Vercel-ready static HTML website.

## Included

- `index.html`
- 26 pages: `a.html` to `z.html`
- `about.html`
- `privacy.html`
- `terms.html`
- Custom `aTz` favicon files
- `style.css`
- `script.js`
- `vercel.json`
- `package.json`
- `robots.txt`
- `site.webmanifest`

## Vercel Deploy

1. Upload this folder to GitHub.
2. Go to Vercel > Add New Project.
3. Import the GitHub repo.
4. Framework Preset: Other.
5. Build Command: leave empty or use `npm run build`.
6. Output Directory: leave empty.
7. Deploy.

## Local Run

Open `index.html` directly in browser.

Optional:
```bash
npm install
npm run dev
```
